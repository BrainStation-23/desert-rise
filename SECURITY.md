# Security Policy

## Supported Versions

Security updates are currently intended for active development targeting:

| Version | Supported |
| ------- | --------- |
| 19.0    | Yes       |

| < 19.0  | No        |

## Reporting a Vulnerability

If you discover a security issue, please report it privately to the maintainers before opening a public issue.

When reporting, include:

- affected module or component
- impact summary
- steps to reproduce
- proof of concept if available
- suggested remediation if known

Please do **not** publish credentials, tokens, customer data, or exploit details in a public issue.

We will review reports, validate impact, prioritize remediation, and coordinate responsible disclosure.
